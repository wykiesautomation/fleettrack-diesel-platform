# Part 7: Modbus TCP Studio

- Cumulative with OPC UA Parts 1–6 and the Local Edge Gateway Agent.
- Adds read-only Modbus TCP connection configuration, register read tests, decoding and register-to-signal mappings.
- Supports FC01, FC02, FC03 and FC04 only.
- Blocks every write function and contains no PLC control implementation.
- Supports Boolean, signed/unsigned 16/32/64-bit values and Float32/Float64 with byte/word order.
- Includes a local Modbus TCP commissioning simulator.
