# All Cyan Action Contrast Final
- Applies dark navy text to every identified bright-cyan action across the application.
- Covers Add Asset or Vehicle, Connect New Device, Live, Tracking History, Evidence Centre, Quick Calibration, claim and save/deploy primary actions.
- Covers normal, visited, hover and active browser states.
- Keeps disabled actions dark slate with readable light text.
- Loads after the previous shared contrast CSS so page-specific rules cannot override it.
- Preserves the cumulative device selector, board profiles, pins, calibration and centralized Data Management workflow.
