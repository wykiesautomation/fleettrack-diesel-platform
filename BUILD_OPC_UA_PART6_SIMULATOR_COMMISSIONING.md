# OPC UA Part 6: Simulator & Commissioning Centre

- Builds cumulatively on the Part 5 Local Edge Gateway Agent.
- Adds a local read-only OPC UA server with seven realistic industrial nodes.
- Adds a tenant-scoped commissioning checklist and downloadable JSON report.
- Tests gateway heartbeat, connection, browse, read, mapping, live values, quality, offline queue, recovery and read-only enforcement.
- No writes, methods, setpoints, motor commands or alarm acknowledgements are implemented.
