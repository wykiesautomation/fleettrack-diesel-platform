# Part 8: Modbus RTU Studio
- Built cumulatively on the corrected Part 7 baseline.
- Adds RS-485 serial configuration, COM-port discovery, read testing, mapping and a virtual-serial commissioning simulator.
- Supports FC01, FC02, FC03 and FC04 only.
- Validates baud, parity, data bits, stop bits, slave ID, timeout, retries and inter-request delay.
- No Modbus write calls or PLC/device control implementation exists.
