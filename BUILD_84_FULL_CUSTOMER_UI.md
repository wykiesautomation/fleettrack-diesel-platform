# Build 84 Full Customer UI Alignment

This build aligns the complete customer navigation shell and the principal live workflows to the REV28 visual language: Fleet Overview, Asset Monitoring, Fleet Tracking entry, Assets, Asset & Device Setup, Devices & Sources, Signals & I/O Studio, Trends & Limits, Alarm Centre entry, Email Notifications, Integrations and Billing.

Mobile trackers are separated from physical boards and no longer display a legacy hardware profile or GPIO workflow. Existing Flask routes, database writes and APIs remain the functional backend.
