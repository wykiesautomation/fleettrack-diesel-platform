# Global Button and Link Contrast Fix

- Applies the approved white-text, cyan-border and cyan-hover treatment across AssetTrack 360.
- Prevents visited links from reverting to browser purple on dark navy backgrounds.
- Keeps normal content links bright cyan and button-like links white.
- Uses dark navy text on bright cyan hover and active states.
- Adds a lime keyboard-focus outline and readable disabled states.
- Loads as the final shared CSS layer after page-specific styles.
- No backend, customer, device, token, telemetry, assignment or timeout behavior is changed.
