# WROOM Output Web Safety Final

- Output Latest state now comes from fresh firmware feedback, not the last queued command.
- WROOM DO1 ON and Pulse are blocked in the UI and server when Local Arm is inactive.
- OFF remains available as the safe action while ONLINE with fresh physical feedback.
- Simulation locks all physical web output commands.
- Existing device identity, token, telemetry, assignments and customer data are preserved.
