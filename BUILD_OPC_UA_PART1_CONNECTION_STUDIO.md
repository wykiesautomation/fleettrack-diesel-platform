# OPC UA Part 1: Connection Studio

- Adds a tenant-scoped OPC UA Connection Studio.
- Validates OPC endpoint, security policy/mode, authentication and secret references.
- Enforces read-only mode server-side.
- Assigns a local Edge Gateway and stores no plain credentials.
- Adds an authenticated Edge Gateway test-result API and audit trail.
- Does not falsely claim that the cloud website can reach the OT OPC server.
