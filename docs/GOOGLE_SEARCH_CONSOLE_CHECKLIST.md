# Google Search Console Checklist

1. Verify the production HTTPS domain.
2. Submit `/sitemap.xml`.
3. Inspect and request indexing for the homepage and each public landing page.
4. Confirm private URLs are excluded through `noindex` and robots controls.
5. Review Page Indexing, Core Web Vitals and HTTPS reports.
6. Track queries, pages, countries, devices, click-through rate and average position.
7. Record a baseline before publication and compare at 30, 60 and 90 days.
8. Fix duplicate titles, missing canonicals, 404 pages and redirect chains.
9. Revalidate structured data with Google Rich Results Test.
10. Never publish false customer numbers, reviews or unsupported performance claims.
