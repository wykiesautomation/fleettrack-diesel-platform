# Mobile Phone Tracker Test

1. Open an asset and select Add Phone Tracker.
2. Open `/mobile-tracker` on the phone.
3. Enter the one-time code within 30 minutes.
4. Grant precise location access.
5. Select Start Tracking and keep the page open during the browser trial.
6. Confirm the device appears in Device Registry and positions appear in Tracking History.
7. Select Stop Tracking when the test is complete.

The web trial is not intended for hidden or 24/7 background tracking. A production Android foreground-service app is the next stage.
