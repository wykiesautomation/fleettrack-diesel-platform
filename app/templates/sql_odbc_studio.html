Credential Safety

Only the environment-variable reference is kept in the website. The ODBC secret stays on the Edge computer.

Permanent Read-Only Contract

Allowed: one SELECT or WITH statement.

Blocked: INSERT, UPDATE, DELETE, MERGE, DDL, EXEC/CALL, SELECT INTO, transactions and multiple statements.

Autocommit is disabled. Runtime always rolls back and never commits.

Supported

SQL Server, PostgreSQL, MySQL, MariaDB, Oracle, DB2, Sybase, Access and generic ODBC drivers.
