Access Rules

Device tokens remain stable. Every telemetry request checks the customer subscription.

  • Trial or paid entitlement: tracking accepted
  • Payment period ended: 3-day grace period
  • Grace expired: API returns HTTP 402
  • Payment restored: existing device token works again

Tokens are rotated only if compromised, replaced or reassigned.
