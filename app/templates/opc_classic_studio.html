Local Installation

powershell -ExecutionPolicy Bypass -File client\opc_classic\install_bridge.ps1

Install vendor OPC Core Components and a matching 32-bit or 64-bit COM bridge on the Edge computer.

DCOM Boundary

DCOM remains local to the Windows OT network. AssetTrack 360 uses outbound HTTPS from the Edge Gateway and never exposes DCOM to the internet.

Permanent Safety Contract

Implemented: server list, browse, read, quality/timestamp collection and mapped telemetry.

Not implemented: OPC Write, setpoints, motor commands, procedure execution, alarm acknowledgement or PLC control.

Compatibility

OPC DA 2.x/3.x through a locally installed COM-compatible client. Vendor-specific registration and DCOM rights must be commissioned on the Windows Edge computer.
